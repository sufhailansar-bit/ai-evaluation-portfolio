# AI Evaluation Portfolio

Prepared by Mohammad Sohail Akhtar

Five structured evaluation samples covering:
- AI response comparison
- Fact-checking and hallucination detection
- Medical AI content evaluation
- Search quality evaluation
- Instruction-following assessment

Each sample is scored against defined criteria, and claims are checked against NIH/NLM, NIDDK, NHGRI, NCBI and NHS references.

Note: These are practice evaluations, not paid client work. Medical content is assessed for answer quality only and is not medical advice.
